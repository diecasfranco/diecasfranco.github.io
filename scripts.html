Open-source Scripts

NanoTax

Produces a unified table combining contig information (coverage, length, GC%) and taxonomy for assemblies from Nanopore and Illumina reads. Supports blastn/blastx/diamond and integrates minimap2 or bowtie2 mapping.

Python Nanopore Taxonomy Metagenomics

TheMiteRoom — Nanopore Pipeline

Official pipeline for Nanopore amplicon sequencing based on consensus sequences. Builds OTU and zOTU (ASV) tables from Amplicon Sorter output using USEARCH and VSEARCH commands.

Bash Nanopore OTU Amplicon
View on GitHub

Amplicon Sequencing Tutorial

Step-by-step tutorial for 16S/18S/ITS amplicon analysis: SRA download, FastQC, Trim Galore, PEAR merging, VSEARCH dereplication, chimera removal, OTU/ASV clustering, and SINTAX taxonomy.

16S ITS VSEARCH Tutorial

symCAP

Symbiosis Custom Annotation Pipeline. Annotates genomes from primary endosymbionts in planthoppers using HMMER, RNAmmer, tRNAscan-SE, and MAFFT for codon-aware alignment.
