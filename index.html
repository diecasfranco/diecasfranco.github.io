About Me

I am a microbiologist with broad expertise in microbial ecology and host-associated microbiomes. My research spans Antarctic and marine sediment microbiology, insect endosymbiosis, clinical microbiome studies, and environmental microbiology in tropical and semi-arid ecosystems.

Currently I work on honeybee gut microbiomes, applying 16S amplicon sequencing and custom bioinformatics pipelines to understand how diet, environment, and colony management shape microbial communities in Apis mellifera.

I develop open-source Python tools for interactive analysis and visualisation of microbiome data, making complex multi-sample results accessible through self-contained HTML reports.

Open-source Scripts

NanoTax

Produces a unified table combining contig information (coverage, length, GC%) and taxonomy for assemblies from Nanopore and Illumina reads. Supports blastn/blastx/diamond and integrates minimap2 or bowtie2 mapping.

Python Nanopore Taxonomy Metagenomics
View on GitHub

TheMiteRoom — Nanopore Pipeline

Official pipeline for Nanopore amplicon sequencing based on consensus sequences. Builds OTU and zOTU (ASV) tables from Amplicon Sorter output using USEARCH and VSEARCH commands.

Bash Nanopore OTU Amplicon
View on GitHub

Amplicon Sequencing Tutorial

Step-by-step tutorial for 16S/18S/ITS amplicon analysis: SRA download, FastQC, Trim Galore, PEAR merging, VSEARCH dereplication, chimera removal, OTU/ASV clustering, and SINTAX taxonomy.

16S ITS VSEARCH Tutorial
View on GitHub

Tomato Metagenomics

Bioinformatic pipelines for the manuscript "Metagenomic Analysis of the Tomato Microbiome in Colombia Reveals Bacterial Diversity, Potential Pathogens, and Resistance Determinants".

Metagenomics Bacteria Resistome
View on GitHub

symCAP

Symbiosis Custom Annotation Pipeline. Annotates genomes from primary endosymbionts in planthoppers using HMMER, RNAmmer, tRNAscan-SE, and MAFFT for codon-aware alignment.

Python Annotation Symbiosis Genomics
View on GitHub

TRYOCC Metagenomics

Amplicon Analysis Pipeline
